# Шрифты

Исходники взяты из официальных архивов Финуниверситета: https://www.fa.ru/university/structure/university/uso/mediafiles/ (Golos-Text.zip, Open-Sans.zip).
Для веба оставлены только латиница, кириллица и знаки, файлы сконвертированы в WOFF2 (fontTools).
