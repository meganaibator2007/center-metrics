Система учёта показателей деятельности центра

Преподаватели вносят данные о своей работе, система сама считает баллы, руководство видит контроль сдачи и сводный отчёт. Это кликабельный прототип на HTML и CSS в фирменном стиле Финуниверситета; серверную часть (Java, Spring Boot) подключаем в следующих спринтах.

Что уже есть

  • Все основные экраны обеих ролей, переходы между ними
  • Фирменный стиль: цвета, шрифты, логотип, сетка, кнопки и табы по брендбуку
  • Проверка форм средствами HTML: обязательные поля, числа больше нуля, даты в пределах периода
  • Адаптивная вёрстка для телефона и печатная версия отчёта
  • Ни одной строки JavaScript и ни одного inline-стиля: шаблоны сразу переносятся в Thymeleaf
